# 经验库索引（_INDEX.md）

> **本文件是空骨架**。安装包只提供经验库的目录结构与标签词表，不携带任何经验正文。
> 每写入一篇新经验文档后，把该文档补进下表；也可由 `wuliang-ctx-memory` 插件的检索结果反推整理。

## 怎么用

1. 写新经验前先读 `_TAXONOMY.md`，从词表取 `domain` / `subject` / `stack` / `problem` / `level`，**不得自造**。
2. 按域放到对应目录：`SEC/` `CTF/` `REV/` `DEV/` `OPS/` `AI/` `MOB/` `GAME/` `DOC/` `DATA/`。
3. 每篇文档开头写 YAML frontmatter（`id` 为 `<域>-<三位序号>`，全库唯一）。
4. 在下面表格追加一行。
